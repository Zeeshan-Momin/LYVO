# Security Policy

## Supported Versions

We actively support security updates for the following versions:

| Version | Supported |
| --- | --- |
| 1.1.x | Yes (Latest) |
| 1.0.x | No |

## Reporting a Vulnerability

If you discover a potential security vulnerability within LYVO, please do not disclose it publicly or file a public GitHub issue. Instead, report it responsibly:

1. Send an email to the repository owner: `security@lyvo.yourdomain.com` (placeholder)
2. Detail the exact steps required to reproduce the vulnerability, including payload examples, paths, headers, and affected components.
3. We will acknowledge receipt of your report within 48 hours and coordinate a patch or mitigation sequence within 7 days.
